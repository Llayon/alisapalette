# Local ChromaStyle fonts

Unmodified WOFF2 subsets of Cormorant Garamond (600–700), Inter (400–700),
and JetBrains Mono (400–700), served locally by the application.

Sources: the official Google Fonts CSS endpoint and fonts.gstatic.com.
`sources.json` records the exact download URLs and byte sizes of every file.
`fonts.css` preserves the original unicode ranges and variable weight ranges.
No external requests are required at runtime. Relative paths support hosting
in a repository subdirectory.

Each family is distributed under the SIL Open Font License 1.1. Original
copyright and license texts are included as `inter-OFL.txt`,
`cormorantgaramond-OFL.txt`, and `jetbrainsmono-OFL.txt`, obtained from the
corresponding `ofl/<family>/OFL.txt` files in the official google/fonts repository.
