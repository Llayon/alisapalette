# План доработки ChromaStyle

Цель — устранить ошибки загрузки, редактирования палитры и экспорта, закрепить результат проверками и упростить поддержку. Каждый этап должен иметь отдельную проверку результата; исправления поведения предшествуют переносу кода.

Исходная проверка: 84 модульных теста проходят, production-сборка успешна. 76 E2E проходят с изолированными запросами к Google Fonts. Это не доказывает корректность реальной типографики: её необходимо проверить с используемыми шрифтами.

## 1. Воспроизводимые проверки

- [x] Перенести используемые шрифты в локальные ресурсы с лицензиями, кириллицей и необходимыми начертаниями.
- [x] Проверять штатную типографику и отдельно отказ/задержку загрузки шрифтов.
- [x] Сохранять скриншоты, трассировки и URL неудачных запросов при падениях E2E.

- [x] Проверить запуск из чистого checkout и освобождение порта после тестов на Windows.

Готовность: тесты используют реальные локальные шрифты приложения и воспроизводимо завершаются. Перед исправлением каждого дефекта появляется проверка, воспроизводящая его.

## Зависимости и организация

Этапы 2–5 опираются на воспроизводимые проверки; рефакторинг выполняется после исправлений. Каждый этап подходит для отдельного PR. Оценка полного объёма — 6–10 рабочих дней одного разработчика, уточняется после первого этапа.

Аудит npm запланирован отдельно: автоматическая проверка разрешений отклонила передачу списка зависимостей во внешний npm registry. Для npm audit требуется запрошенное разрешение пользователя.
